# Дорожная карта

| Этап | Состав | Статус |
|---|---|---|
| 1. MVP | Репозиторий, навык, CLI (`init`, реестры, `audit`, `status`, `site build/serve`), синтетическое дело, сайт локально, установка в Claude Code и Codex | **готово**, кроме проверки в Codex (не установлен на машине разработки) |
| 2. Процесс исследования | `kin next` со скорингом (ценность, стоимость, доступность, лимиты), команды жизненного цикла задач/гипотез с историей решений, роли агентов (`roles/*.md` → `.claude/agents`, `.codex/agents`), протокол независимого ревью, шаблоны заданий `tasks/`, `site publish` с рецептами выкладки, модуль «сведения семьи», модуль «запросы в архивы» | план |
| 3. Совместимость и эксплуатация | MCP-сервер (stdio), GEDCOM импорт/экспорт, полный JSON-экспорт/импорт без дублей, `kin migrate`, `backup/restore`, SQLite-индекс, двуязычные сообщения CLI и документация, CI | план |

Каталог архивов (`references/`) расширяется независимо от платформы — отдельными изменениями справочников.
