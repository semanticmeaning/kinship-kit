Каталог архивов (`references/`) расширяется независимо от платформы — отдельными изменениями справочников.

## Решение: перевод сообщений об ошибках отложен (2026-11-02)

Внешнее ревью предлагало перевести CLI на ключи сообщений. Сейчас это не окупается:
- подмены фраз в готовом выводе уже нет — `t()` переводит только подписи интерфейса по точному совпадению,
  данные дела через неё не проходят;
- хрупкость словаря закрыта тестом `TestTranslations`: правка русской подписи без перевода роняет проверку;
- около 170 сообщений об ошибках — только на русском. В основном сценарии их читает агент и объясняет пользователю
  на его языке; неудобно лишь англоязычному человеку, работающему в терминале без агента.

**Когда вернуться:** первый запрос от англоязычного пользователя, работающего с `kin` напрямую. Тогда — ключи
сообщений с переводами (ошибки `KinError`, инструкция скачивателей, вывод `doctor`), объём ~день.
