# Дорожная карта

| Этап | Состав | Статус |
|---|---|---|
| 1. MVP | Репозиторий, навык, CLI (`init`, реестры, `audit`, `status`, `site build/serve`), синтетическое дело, сайт локально, установка в Claude Code и Codex | **готово**, кроме проверки в Codex (не установлен на машине разработки) |
| 2. Процесс исследования | `kin setup` (первый шаг), схема v2 + `kin migrate`, `kin next`, жизненный цикл задач и гипотез с историей решений, защита от повторных поисков, независимое ревью, роли агентов (Claude Code + Codex), шаблоны заданий, запросы в архивы, `site publish` + git-хук + рецепты выкладки | **готово** |
| 3. Совместимость и эксплуатация | MCP-сервер (stdio), GEDCOM импорт/экспорт, полный JSON-экспорт/импорт без дублей, `backup/restore`, SQLite-индекс, двуязычные сообщения CLI и документация, модуль «сведения семьи» (форма → черновик → решение исследователя) | план |

Каталог архивов (`references/`) расширяется независимо от платформы — отдельными изменениями справочников.
