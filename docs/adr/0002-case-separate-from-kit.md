# ADR-0002. Дело — отдельная приватная папка, вне репозитория набора

Дата: 2026-11-01. Статус: принято.

**Решение.** Код и данные никогда не лежат в одной папке. `kin init` отказывается создавать дело внутри набора или
папки навыка; `kin doctor` проверяет размещение и предупреждает о внешнем remote; `tools/check_repo.py` (pre-commit, CI)
ищет в наборе файлы дел и личные сведения по содержимому, а не по `.gitignore`. Личный стоп-лист — вне репозитория
(`KIN_DENYLIST` или `~/.config/kinship-kit/denylist.txt`).

**Последствия.** Публикация набора не может случайно унести данные семьи; приватный репозиторий дела создаётся
только по явному выбору пользователя.
