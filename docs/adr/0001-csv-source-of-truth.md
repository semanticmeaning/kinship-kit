# ADR-0001. Текстовые реестры CSV — единственный источник истины

Дата: 2026-11-01. Статус: принято.

**Контекст.** Исследование длится годами, данные правят человек и несколько ИИ-агентов, нужна история изменений
и перенос между машинами. Исходное дело уже ведётся в CSV-реестрах и git; это работает на сотнях записей.

**Решение.** Факты хранятся только в `registry/*.csv` по схеме `kin/schema.json`. Любые другие представления
(SQLite-индекс, `publish/`, `site/`, GEDCOM) — производные и пересобираются. Запись — только через `kin`
(проверка схемы и ссылок, блокировка, атомарная замена файла, журнал).

**Последствия.** + Диффы читаемы, слияния в git понятны, нет зависимости от СУБД. − Поиск по большим делам медленнее
(решается производным индексом). − Ручная правка CSV возможна — её ловит `kin audit`.
