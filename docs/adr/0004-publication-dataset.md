# ADR-0004. Сайт строится только из публикационного набора с проверкой утечек

Дата: 2026-11-01. Статус: принято.

**Решение.** `kin site build` сначала строит `publish/<профиль>/data.json` фильтром (`private`/`public`), затем
`tree.json`; обе стадии проверяются на утечки (имена скрытых людей в любом падеже, их ID, e-mail, телефоны,
локальные пути). При находке сборка удаляется и команда завершается ошибкой. При сомнении — скрыть.
Корень схемы, если он скрыт (обычно живой автор), заменяется ближайшим видимым родственником; наружу уходит
только смещение колена.
