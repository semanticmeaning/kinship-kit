# ADR-0003. Вся логика — в CLI `kin` внутри папки навыка

Дата: 2026-11-01. Статус: принято.

**Решение.** Пакет `kin` (Python 3.10+, только стандартная библиотека) лежит в `skills/kinship-kit/kin/`.
Установка навыка = копирование одной папки; в ней сразу есть и методика, и инструмент (`python3 <навык>/kin.py`).
Навык, будущий MCP-сервер и сайт вызывают `kin`, а не дублируют логику.

**Проверено (2026-11-01, по документации):** Claude Code ищет навыки в `~/.claude/skills/<имя>/SKILL.md` и
`.claude/skills/` проекта; Codex — в `~/.agents/skills/` и `.agents/skills/` от текущей папки до корня репозитория.
Обязательны `name` и `description`. Агенты: Claude Code — Markdown в `.claude/agents/`, Codex — TOML в `.codex/agents/`
(понадобится генерация из общих файлов ролей на этапе 2).
