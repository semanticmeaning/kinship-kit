## Порядок
1. Определить архив по истории территории (принадлежность места в нужный период — `kin show L-…`; губерния/уезд/волость тогда, область/район теперь).
2. Путеводитель → фонды учреждения (консистория, приход, волостное правление, ЗАГС, военкомат, сельсовет) → описи → дела по годам.
3. Для каждого найденного дела записать шифр (фонд, опись, дело), годы, состав, доступ (онлайн, читальный зал, запрос, платно).
4. Ничего не найдено в каталоге — это ограничение каталога, а не отсутствие документов: записать покрытие и варианты.

## Запись результата
- Каждый просмотренный каталог/опись — `kin search add --task {task_id} …` (результат, ограничения источника, когда повторить).
- Найденные дела — в `sources_to_check` следующих задач (`kin task new metric-books …` или `archive-request`).
- Платный доступ — только после `kin task consent`.
