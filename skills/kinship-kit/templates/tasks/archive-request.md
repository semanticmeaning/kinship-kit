## Подготовка (делает агент)
1. Канал подачи: госархивы РФ по 59-ФЗ принимают обращения через портал госуслуг или личный кабинет/форму архива, а не по e-mail;
   другие страны и учреждения — по их правилам. Проверить на сайте архива на дату подачи.
2. Текст: заявитель (данные заполняет пользователь), что ищем (ФИО в вариантах написания, годы, место в тогдашнем
   административном делении, известные шифры), что просим (архивная справка / копия), формат ответа.
   **Степень родства в тексте не указывать**, если архив не требует для доступа.
3. Сохранить текст: `requests/{task_id}.md`; зарегистрировать — `kin request add --task {task_id} --recipient … --subject … --channel … --text requests/{task_id}.md`.

## Отправка и ответ (делает пользователь)
- После отправки: `kin request sent Q-… --date <дата> --number <номер обращения>` (срок ответа — +30 дней).
- Платное (счёт архива) — только решение пользователя.
- Ответ: `kin source add <ответ>` → `kin request answer Q-… --artifacts A-…` → утверждения → `kin task done {task_id}`.
