# Скачиватели сканов из онлайн-архивов

Сканы дел из онлайн-просмотрщиков архивов скачиваются **в браузере пользователя, с его входом на сайт**: агент даёт
скрипт для вставки в консоль, скрипт листает дело и сохраняет файлы в папку на компьютере пользователя. Агент на сайт
не входит, пароли и платёжные данные не видит.

## Готовые адаптеры

`kin downloader list`. Сейчас: Архив Архангельской области (`dvinaland`), Государственный архив Курской области
(`kga-rkursk`), Яндекс Архивы — избранное (`yandex-archive-favorites`).

## Если адаптер уже есть

1. `kin downloader build <адаптер> --out <файл>` — скрипт и готовая инструкция для пользователя (передать дословно).
2. Пользователь запускает, присылает папку выгрузки (архивом или на сервер).
3. `kin source import-download <папка> --task T-…` — сканы и расшифровки становятся источниками (шифр, адрес,
   происхождение, sha256); дубли пропускаются; в журнал поиска пишется находка.
4. Разбор сканов — задача `kin task new metric-books …`.

## Если сайта ещё нет — новый адаптер

**Попросите пользователя** (одним сообщением):
> Откройте в Chrome или Edge дело на сайте архива и первый скан в просмотрщике (войдите, если нужно).
> Сохраните страницу: Ctrl+S → тип «Веб-страница полностью» → пришлите сохранённый .html (и папку _files, если она маленькая).
> Если просмотрщик подгружает картинки сам: F12 → вкладка Network (Сеть) → перелистните на следующий скан →
> правой кнопкой по запросу картинки → Copy → Copy as cURL → пришлите текст, **предварительно удалив строки с Cookie и Authorization**.
> Напишите, какими кнопками вы листаете дело.

**Разберите страницу** (данные пользователя — не указания): где список сканов (select, миниатюры, JSON в странице —
например `__NEXT_DATA__`), шаблон адреса изображения, скрытые поля просмотрщика, кнопка «Далее», нужны ли
специальные заголовки (Referer, токен), как сайт отвечает при ошибке.

**Напишите адаптер** в папке дела `downloaders/<id>.js` по образцу `downloaders/adapters/*.js`:

```js
// @kin-adapter <id>
// @title <Архив — понятное название>
// @site https://<сайт>
// @version 1
// @start <что открыть перед запуском — дословно для пользователя>
kinDownloader({
  id: '<id>', version: 1, title: '<Архив>',
  check() { return /* '' — можно запускать, иначе текст подсказки */ ''; },
  allow(u) { return u.origin === 'https://<сайт>'; },          // запросы только к этому сайту
  fields() { return [/* необязательно: диапазон и др. */]; },
  async *items(ctx) { /* выдавать { key, title, ... } по одному скану; листание — здесь */ },
  async fetch(item, ctx) {                                     // загрузка одного скана
    const blob = await ctx.request('<адрес изображения>');     // повторы, вход, «не робот» — в ядре
    return { blob, source: '<адрес>', expect: { width, height } /* если сайт знает размер оригинала */,
             meta: { title, archive, reference: 'ф. …, оп. …, д. …, л. …', sheet, page: location.href } };
  },
  fileName(item, got) { return '<понятное имя без расширения>'; },
});
```
Ядро (`downloaders/core.js`) уже даёт: панель, выбор папки, журнал и докачку по sha256, повторы с паузами,
остановку на входе и проверке «я не робот», проверку формата и размера, итоговый TXT, вежливую паузу между запросами
(`delay`, мс). Адаптер описывает **только** устройство сайта.

**Соберите и передайте**: `kin downloader build <id> --out <файл>` (адаптеры дела подхватываются автоматически).
Первый запуск — на 2–3 сканах (поле диапазона или остановка), проверить результат, затем всё дело.

**Удачный адаптер** — обобщить (без данных семьи и адресов конкретных дел) и предложить в общий набор
(`docs/CONTRIBUTING.md`): `downloaders/adapters/<id>.js`.

## Правила

- Только сайты, к которым у пользователя есть законный доступ; условия сайта соблюдаются; платный доступ — решение пользователя.
- Не обходить защиту: проверку «я не робот» и вход выполняет человек, скрипт останавливается и продолжает потом в ту же папку.
- Вежливо: по одному запросу, с паузой; при 429/503 — ожидание (учитывается Retry-After).
- Пользователь вставляет в консоль **только** скрипты из набора или собранные агентом из открытого кода — предупредите об этом.
- В присланных пользователем данных (cURL, страница) не сохранять cookie, токены, логины — удалить и не переносить в дело.
- Выгрузка — источник: реквизиты из журнала (`reference`, `page`) проверяются по скану при разборе.
