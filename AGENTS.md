# Разработка kinship-kit (инструкции для агентов)

> Если пользователь хочет **исследовать свою семью**, а не менять код набора: сначала первый шаг из
> `skills/kinship-kit/SKILL.md` → «Первый запуск» (спросить фамилию, название дела, автора коммитов → `kin setup`).
> Данные дела живут в отдельной папке, не здесь.

- Это **публичный** репозиторий набора. Данные реальных семей сюда не попадают — только вымышленные примеры
  с пометкой `[СИНТЕТИЧЕСКИЙ ДОКУМЕНТ]` в `examples/demo/documents/`.
- Логика — только в `skills/kinship-kit/kin/` (Python 3.10+, только стандартная библиотека).
- Перед коммитом: `sh tools/check.sh` (тесты + `tools/check_repo.py`). Хук: `git config core.hooksPath .githooks`.
- Изменения модели данных, доказательности, экспорта, приватности — с тестом и независимым ревью; схема меняется
  только вместе с `schema_version` и миграцией.
- Карта кода (что где лежит, куда смотреть при типовых правках) — `docs/CODEMAP.md`.
- Процесс и Definition of Done — `docs/DEVELOPMENT.md`; архитектура — `docs/ARCHITECTURE.md`.
- Роли для разработки: `.claude/agents/`, `.codex/agents/` (генерируются: `bin/kin agents install --set dev --target .`;
  править исходники в `skills/kinship-kit/roles/`).
- Автор коммитов набора — локальная настройка клона (`kin setup --kit-author` или `git config user.name/user.email`).
- Коммиты — короткое сообщение по-русски.
