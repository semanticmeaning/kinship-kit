# Изменения kinship-kit

Формат: версия (метка git `vX.Y.Z`), дата, что нового. **Схема данных** — нужно ли выполнить `kin migrate` в своих делах.
Обновление: `kin upgrade check` → `kin upgrade apply` → в каждом деле `kin migrate --dry-run`. Данные дел не затрагиваются.

## [0.4.3] — 2026-11-02
Схема данных без изменений (v2).

- Сайт-схема снова двуязычная: кнопка RU/EN, выбор запоминается. Сборка выпускает `index.ru.html` и `index.en.html`
  на одних данных и `index.html` на языке дела; английская версия — замена подписей интерфейса по словарю
  `kin/web/i18n-en.json` (данные дела не переводятся). Названия колен — на обоих языках.

## [0.4.2] — 2026-11-02
Схема данных без изменений (v2).

- Исправлено: на карточках сайта-схемы пропали иконки пола (файлы `icons/` не попадали в сборку). Пересоберите сайт:
  `kin site build`. Добавлена проверка, что все файлы, на которые ссылается страница, есть в сборке.

## [0.4.1] — 2026-11-02
Схема данных без изменений (v2).

- Безопасность сайта: если среди источников есть сохранённые веб-страницы, SVG или XML, они публикуются только как текст
  (`.txt`) — их скрипты не выполняются на вашем сайте. Пересоберите сайт: `kin site build`.

## [0.4.0] — 2026-11-02
Схема данных без изменений (v2) — `kin migrate` не нужен. **Изменился формат данных сайта (`tree.json`):**
если вы делали полную копию страницы (`theme/index.html`), пересоздайте её: `kin site theme init --full` в новой папке
темы и перенесите свои правки (`custom.css` продолжает работать).

- Новый шаблон сайта-схемы (на основе схемы, отработанной на реальном исследовании): полотно с перемещением и масштабом,
  колена, линии к детям от пары родителей, уровни доказанности на связях, метки гипотез («родитель?», «одно лицо?»),
  раскрытие ветвей, режим «По семьям» (цвет по фамилии при рождении, фильтр семьи), вкладка «Линии поиска»
  с открытыми гипотезами, профиль: сведения, факты и связи с подтверждением, источники-шифры.
- Документы к фактам: значок «документ» с просмотрщиком (листание, масштаб) и значок «внешняя ссылка».
  Файлы источников копируются в сайт: приватно — все, публично — только `scan_publication=allow`.
- Принятые «сведения семьи» показываются в профиле (только приватная версия).
- Настройки дела: `family_variants` (варианты фамилий одной семьи) и `site.search_aliases` (варианты написания для поиска)
  — в `case.json`.

## [0.3.1] — 2026-11-02
Схема данных без изменений (v2).

- Исправлено: в 0.3.0 `kin` не запускался на Python 3.10–3.11 (синтаксис f-строк в модуле скачивателей).
  Добавлена проверка, которая не даст повторить ошибку.

## [0.3.0] — 2026-11-02
Схема данных без изменений (v2) — `kin migrate` не нужен.

- Скачиватели сканов из онлайн-архивов: общее ядро (`downloaders/core.js`) — панель, папка, журнал и докачка по sha256,
  повторы, остановка на входе и проверке «я не робот», проверка формата и размера, итоговый TXT; адаптеры:
  Архив Архангельской области, Государственный архив Курской области (ЕАИС), Яндекс Архивы — избранное.
- `kin downloader list|build` — скрипт для консоли браузера и инструкция для пользователя.
- `kin source import-download` — выгрузка → источники дела (шифр, адрес, происхождение, расшифровки), без дублей.
- Методика нового сайта: пользователь присылает сохранённую страницу просмотрщика → агент пишет адаптер в папке дела.

## [0.2.0] — 2026-11-02
**Схема данных: v1 → v2 — выполните `kin migrate` в делах, созданных версией 0.1.0** (резервная копия создаётся сама).

- Первый шаг `kin setup`: фамилия, название дела, автор коммитов — явно; личный стоп-лист.
- Процесс исследования: `kin next`, жизненный цикл задач и гипотез, история решений, защита от повторных поисков,
  согласие пользователя на платное и внешние сервисы, шаблоны заданий, запросы в архивы.
- Независимое ревью значимых выводов (привязано к решению, засчитывается по журналу), роли агентов для Claude Code и Codex.
- Обмен и сохранность: полный экспорт/импорт JSON без дублей, `kin backup` / `kin restore`, GEDCOM 5.5.1, поиск `kin find`.
- MCP-сервер для ИИ-клиентов без командной строки.
- Форма «сведения семьи» на приватном сайте (черновик → решение исследователя).
- Публикация: показ живых по решению автора (`privacy.public_living`), закрытие скрытого вместо остановки сборки
  (`privacy.on_leak=redact`), личная тема сайта дела, выкладка `kin site publish`, демо на GitHub Pages.
- Английский интерфейс, руководство и демо-дело.
- Версии и обновления: `kin --version`, `kin upgrade check|apply`, напоминание в `kin status`.

## [0.1.0] — 2026-11-01
Схема данных v1.

- CLI `kin`: дело, источники с sha256, упоминания, личности, утверждения, связи, места, аудит доказательности, `kin status`.
- Сайт-схема рода: колена, гипотезы, профиль с источниками; публичная сборка без живых с проверкой утечек.
- Навык `kinship-kit` (на основе ex-ussr-kinship-research), синтетическое демо-дело, тесты, проверка приватности репозитория.
